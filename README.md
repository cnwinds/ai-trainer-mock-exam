# ai-trainer-mock-exam

人工智能训练师（二级/技师）备考刷题系统：2025 上海市专项职业技能大赛真题解析 + 新编题库 + 自适应组卷 + AI 评卷闭环。

## 快速开始
```bash
cd exam-app
python server.py   # 仅需 Python 3 标准库
```
浏览器打开 http://127.0.0.1:8848/ （Windows 可直接双击 `启动刷题系统.bat`）。

## 目录
| 路径 | 内容 |
|---|---|
| `exam-app/` | 刷题系统（服务、前端、题库、校验脚本），详见 `exam-app/README.md` |
| `备考输出/` | 2025 真题参考答案与思考路径、答题卷模板、速记卡、参考 notebook |
| `_text/` | 试题 PDF 转出的文本（题库构建来源） |
| `人工智能训练师试题和评分框架0908/` | 2025 赛项原始试题、素材与评分框架 |

> 官方未公布标准答案，题库中答案、解析与新编题均为备考参考。
