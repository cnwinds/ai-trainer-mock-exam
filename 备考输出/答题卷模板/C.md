# C 答题卷（纯净誊抄版）

> 考场另存为：`答题卷.doc`，保存到桌面 `参赛号/C/`。

## 任务一：功能需求

### 需求编号：F-01
**需求描述**：系统接收 Word/PDF 或 JSON 合同后，在可配置时限与规则版本下，对 clauses 实时识别高风险条款（免责、提前解除、未经授权付款等），返回 clause_id、风险类型、等级与证据；支持按风险类型配置启用/停用与匹配阈值。  
**验收标准**：
1. 示例合同 CL1003 必须命中提前解除/免责类；P95 检测响应 ≤3 秒（50 份样例）。
2. 规则启用完整时，指定高风险样例召回 ≥98%，误报 ≤5%。

### 需求编号：F-02
**需求描述**：提供关键字规则库管理：新增/编辑/停用/查询/发布/回滚；规则至少含 keyword_list、风险类型、等级、生效时间、版本、enable_logging；按版本策略生效。  
**验收标准**：
1. 发布后 ≤1 分钟新合同按新版本匹配；无权限返回 403。
2. 版本回滚成功率 100%，审计含操作者、前后版本、时间。

### 需求编号：F-03
**需求描述**：持久化自动命中与人工复核标记；按合同类型、风险类型、时间、相对方、审核状态等统计导出；按 contract_id+clause_id+rule_version 审计追溯；日志含操作者、时间、动作、规则版本、前后状态、原因。  
**验收标准**：
1. 已标记条款 3 秒内可追溯完整证据链，字段完整率 100%。
2. ≥4 维筛选；导出 1 万条 ≤30 秒且必填字段不丢。

## 任务二：方案设计

### （1）流程
数据输入 → 文本预处理 → 条款高风险检测 → 判断①是否含高风险？→ 否：低风险报告；是：人工审核 → 判断②人工是否确认高风险？→ 是：标记告警报告；否：改判保存 → 审计归档统计 → 结果回流规则。

### （2）JSON 规则模板
```json
{
  "rule_id": "R-001",
  "risk_type": "提前解除权",
  "risk_level": "high",
  "keyword_list": ["随时解除合同", "无需承担违约责任", "单方解除"],
  "enable_logging": true,
  "enabled": true,
  "version": "1.0",
  "effective_from": "2024-01-01T00:00:00Z"
}
```

### （3）统计与审计
维度：合同类型、风险类型/等级、相对方、部门、时间、审核状态。  
指标：高风险数/占比、类型分布、确认率、误报率、审核时长、命中 TopN。  
审计：只追加日志；分级权限；可按合同/条款/规则版本追溯。

## 任务三：实现规划

### （1）识别伪代码
校验合同 → 加载启用规则 → 遍历 clauses 并 normalize → 匹配 keyword_list → 生成命中记录（合同/条款/规则/证据/版本）→ 按 enable_logging 写日志 → 返回结果列表。

### （2）标记伪代码
校验权限与状态 → 合并人工 decision/reason → save_mark_to_db → update_statistics → 写审计日志 → 返回成功。

### （3）测试方案
| 类型 | 目标 | 数据示例 | 预期 |
|---|---|---|---|
| 边界值 | 极端输入稳定 | 空 clauses、超长条款、缺 contract_id、特殊字符 | 不崩溃；缺字段 4xx；超长有明确处理 |
| 关键词覆盖 | 命中准、控误报 | 精确词、同义、否定语境、空格干扰、多词命中 | 该中中、否定不误报或多进人工 |
| 压力 | 并发批量性能与不丢数 | 50 并发、1000 份、单份 200 条款 | P95 达阈值；错误率≤1%；日志标记不丢 |
