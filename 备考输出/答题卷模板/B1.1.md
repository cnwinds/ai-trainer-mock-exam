## 任务一：业务框架设计

### 1. 四层框架
| 层级 | 模块 | 说明 |
|---|---|---|
| 输入层 | 菜单库存、用户偏好、订单备注、门店产能、配送状态 | 对接 POS/会员/订单中台 |
| AI 能力层 | 备注 NLP、推荐优惠、需求预测、智能调度 | 低置信转人工 |
| 业务协同层 | 下单、人工校对、后厨、出餐、配送、异常回退 | 人机职责清晰 |
| 输出层 | 结构化工单、推荐结果、制作队列、预估出餐时间、告警报表 | 写入 KDS/配送 |

### 2. 核心技术模块
1. 备注解析（意图+槽位+同义词归一）
2. 推荐与优惠匹配（召回-排序）
3. 高峰流量与产能调度
4. 厨房制作队列优化
5. 人机协同工作台（低置信高亮、日志）

### 3. 协作机制
- 系统：自动解析、推荐、排队、推送
- 接单员：校对低置信/冲突备注，必要时澄清
- 后厨：按结构化工单制作并反馈异常
- 配送员：按派单取送达
- 原则：高置信自动；低置信必须人工确认后进后厨

### 4. 输入输出接口
- 输入：`POST /api/order/create`；`GET /api/store/{id}/capacity`；`GET /api/inventory/{store_id}`；`GET /api/user/{id}/profile`
- 输出：`POST /api/kds/ticket`；`POST /api/recommend/result`；`POST /api/dispatch/assign`；`POST /api/alert`；操作与模型版本日志

## 任务二：业务流程设计

### 1. 人机协同流程（WPS 泳道：用户｜系统｜接单员｜后厨｜配送员）
用户选品填备注 → 系统落单 → NLP 抽槽位 → 置信度≥阈值且无冲突？→ 是：结构化工单；否：人工校对/多轮澄清 → 库存产能检查 → 否：换品/延迟/转店；是：后厨排队制作 → 出餐 → 自取通知 / 分配配送 → 完成并反馈回流。

### 2. 数据层优化
标准词表与归一；备注槽位标注质检；脏数据治理；错单与人工修改回流；用出餐耗时分析瓶颈。指标：词表覆盖≥95%，标注一致率≥95%。

### 3. 模型层优化
意图+槽位模型；置信门控；推荐 A/B；需求预测驱动备料；线上错单率监控。指标：槽位 F1≥0.90，自动通过准确率≥98%。

## 任务三：流程优化
1. **高峰调度**：产能限流与等待预估；多门店分单；备注复杂度加权缓冲。指标：高峰等待、出餐超时率、备注错单率。
2. **多轮点餐**：低置信追问模板；口味选项卡优先；会话状态机可回退。指标：澄清成功率、备注取消率。
3. **门店协作**：工单一键下发 KDS；队列可视化；出餐触发派送。指标：接单到开工、平均出餐、配送准时率。
（转化痛点）个性化推荐与智能满减、常点清单。指标：转化率、复购率、客单价。
