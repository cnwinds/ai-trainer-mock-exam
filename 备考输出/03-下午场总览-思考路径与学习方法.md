## 一、评委下午看什么

| 维度 | 评委真正在找的证据 | 易丢分信号 |
|---|---|---|
| **业务对齐** | 痛点写清、方案对准痛点、不跑题 | 只堆 AI 名词，不提业务指标 |
| **技术可落地** | 有输入/输出、接口、人机边界、异常回路 | 直线流程图，无人工兜底 |
| **可量化** | 指标带单位、阈值、验证方式 | 「提升体验」「更加智能」 |
| **交付完整** | 题面清单逐项打勾；路径与文件名正确 | 漏图、漏表、漏 HTML/notebook |
| **闭环意识** | 数据→模型→系统→实施→审计/复盘 | 只做识别不做回流 |

**一句话**：下午场考的是「二级训练师」——能把运营诉求变成**可设计、可实现、可验收、可推动**的方案。

## 二、通用解题骨架（每题套用）

```
业务痛点（题面关键词圈出）
    ↓
数据 / 模型 / 系统（对应哪一层能解）
    ↓
可量化指标（基线→目标→验证）
    ↓
交付物清单（图/表/代码/伪代码/答题卷）
    ↓
交卷闭环（本地保存 → 平台录入 → 最终提交）
```

**看见题面关键词 → 决策模板**：

| 关键词 | 立刻想到 | 答卷落点 |
|---|---|---|
| 转化/复购 | 推荐、优惠、画像 | 数据层特征 + 模型层召回 |
| 高峰/拥堵 | 限流、排队、产能、多轮澄清 | 调度策略 + 人机协同 |
| 备注/自然语言 | NLP 槽位、置信度、人工校对 | 流程图菱形判断 |
| 时序/市场 | 时间切分、泄漏防控、分布一致性 | TimeSeriesSplit + KS |
| 多产品协同 | 事件中台、工单、日志回写 | 泳道图跨系统 |
| 实施/抗拒 | 4 阶段、试点、培训、资源验证 | 计划表 + 变革措施 |
| 可验收需求 | F-XX + 配置能力 + ≥2 量化标准 | C 题标准写法 |

## 四、如何用 WPS 画泳道图（考场可操作）

1. **插入 → 形状**：矩形=处理，菱形=判断，椭圆=开始/结束，箭头=流向。
2. **先画泳道**：用「表格」做 1 行 N 列，或用长矩形横向分区，泳道标题写角色（用户｜系统｜人工｜后厨｜配送）。
3. **从左到右、从上到下**：正常主路径画完，再补**否分支/异常回路**（低置信→人工校对→回写）。
4. **每个菱形必须有「是/否」两条出边**；否则评委视为流程不完整。
5. **图下加 3–5 行文字说明**：关键节点含义、数据对象、异常处理——图文互证防丢分。
6. **备选加速**：时间紧时用 **Markdown/文字版节点列表 + 简易表格流程**，再尽量补一张形状图；比空白强。

**推荐泳道（按题）**：

- B1.1：用户｜智能点餐系统｜人工接单员｜后厨｜配送员
- B3 协同：门禁｜安防｜事件中台｜工单｜物业人员/业主
- C：输入｜预处理｜检测引擎｜人工审核｜报告/审计

## 五、如何写可量化指标（公式）

```
指标名 = 定义（分子/分母） + 单位 + 基线（现状或估计） + 目标阈值 + 测量窗口 + 验证方式
```

**好例子**：

- 备注槽位抽取准确率 ≥ 92%（人工抽检 200 单/周）
- 高峰时段平均出餐时长 ≤ 12 分钟（对比基线 18 分钟）
- 陌生人告警从发生到推送 ≤ 5 秒；召回率 ≥ 95%（周界侵入样本集）
- 高风险条款检测 P95 响应 ≤ 3 秒；指定样例召回 ≥ 98%

**坏例子（禁止）**：「更智能」「提升满意度」「基本准确」。

**与交易盘感的迁移（仅方法论，非策略）**：你看板块/阶段分布，本质是**分层稳定性**；写指标时也要分层（高峰/平峰、板块/阶段、合同类型），避免「平均好看、局部翻车」。

## 六、错题复盘与刻意练习方法

### 1. 复盘四问（每题练完必写）

1. **漏项**：题面清单哪一项没交？
2. **不可验收**：哪句没有数字/阈值/验证？
3. **无闭环**：哪里缺人工兜底、回流或审计？
4. **时间刺客**：哪一步超时？下次砍什么（装饰性文字）？

### 2. 刻意练习节奏（赛前 7 天示例）

| 天 | 练习 | 成功标准 |
|---|---|---|
| D1 | B1.1 计时 25′ 默写框架+流程图文字版 | 清单 0 漏项 |
| D2 | B3 计时 35′ 全表+两图节点列表 | 4 阶段=10 周 |
| D3 | C 计时 30′ F-01~03+JSON+伪代码+测试 | 每需求≥2 验收 |
| D4 | B1.2 notebook 盲填空 + 导出 HTML | 三图出图 |
| D5 | B2 三类特征+KS 盲写 + 热点测试方案 | 时序切分无泄漏叙述 |
| D6 | B4 15′ + 全套交卷路径演练 | 文件夹命名正确 |
| D7 | 150′ 模拟整场（可删减绘图美化） | 配速表误差 ≤5′ |

### 3. 自学巩固地图

- **看见「备注/条款」** → 练 NLP 槽位/规则匹配 + 置信阈值
- **看见「时序」** → 练 TimeSeriesSplit、禁止随机打乱、特征只用历史窗口
- **看见「多系统」** → 练事件中台与工单回写
- **看见「培训」** → 练柯氏四级：知会→会做→行为改变→业务指标
- **看见「需求」** → 练把形容词改成「阈值 + 样例 + 时限」

### 4. 交卷铁律（每题最后 1 分钟默念）

路径 `桌面/参赛号/题号/` → 文件名 `答题卷.doc`（及要求的 ipynb/html）→ 平台录入 → **最终提交**。题面写 `.doc` 就不要赌 `.docx`。
