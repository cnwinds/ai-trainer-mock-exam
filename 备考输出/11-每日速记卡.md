## 卡 C｜A 易错 15 条（Day2 / Day7）

1. 去标识化后仍不可随意改用途（目的限制在）。  
2. 公平算法 ≠ 免责（历史偏见仍须治理）。  
3. PCA ≠ 选原始特征（线性组合主成分）。  
4. L2 ≠ 稀疏归零（稀疏多看 L1；L2 收缩）。  
5. 复杂度 ≠ 运行秒数（渐近量级）。  
6. 同比上升 ≠ 营销唯一因果。  
7. 职业守则 ≠ 薪酬晋升制度。  
8. 磁盘清理 ≠ 碎片整理/杀毒。  
9. 忠诚度 KPI → **复购**，不是新增/PV。  
10. 菱形=判断；平行四边形=I/O；ERD 实体=矩形。  
11. 保健因素消除不满 ≠ 成就激励。  
12. 看板核心=可视化+限 WIP（非必须固定迭代）。  
13. 关键路径=**最长路径**定工期。  
14. 集成学习不含普通 SVM；AI 特有攻击不含 SQL 注入。  
15. 零初始化权重不推荐；Log-Cosh ≠ 聚类损失。

### 判断口诀（30 秒）

- **错**：伦理不演进｜去标识乱改用途｜公平免责｜同比唯一｜PCA 挑原特征｜L2 归零｜复杂度=秒  
- **对**：监督重预防｜爱岗含终身学习｜二八抓头部｜反向传播=链式｜K 折｜BN｜生命周期四阶段  

### 多选「杀掉项」

自动化别优先情感客服｜SVM≠集成｜SQL≠AI特有｜选结构不问语言流行｜勿全零初始化｜Log-Cosh≠聚类  

### 简答 6 题 30 秒骨架

1. **流程改进**：策略（删冗/标准/自动/KPI）+ 路径（启诊设试推收）  
2. **竞品**：功能｜用户生态｜商业增长 + 各举一点  
3. **GBDT 过拟合**：数据扩充/清洗泄漏+分层CV｜限深/min_samples｜subsample/列采样｜正则｜小 lr+早停（≥5，含数据+模型层）  
4. **智能联动**：画像个性化｜事件自动化｜共性=数据互通/事件总线/统一身份  
5. **AI 项目差异**：完成定义难｜工期不确定｜质量含效果与漂移 → 里程碑/实验缓冲/护栏指标  
6. **业务→需求**：模型任务｜性能度量（离线+在线+护栏）｜数据需求（字段/样本/质量）

## 卡 E｜B2 默写骨架 + 禁区（Day4）

### 三特征（可当场默写）

1. **时段均涨跌**：hour→早/午/尾盘；`index×date×period` 上 `mean(pct_change)`  
2. **板块×阶段**：`groupby(sector, market_phase)` → 均涨跌 / 上涨概率  
3. **近 5 日趋势**：按指数 `rolling(5).sum()`（仅历史窗口）再按指数×板块汇总  

### 切分与 KS

- 按 datetime **排序**；TimeSeriesSplit / 时间比例；测集时间 **晚于** 训集；**禁止随机 shuffle**  
- KS：测集（分板块/阶段）`pct_change` vs 全体；p 小 → 分布不一致 → 分层补齐或重切  
- **KS 一句话**：比的是两组涨跌幅经验分布是否同分布，不是用来选股。

### 热点测试三件套

- **目标**：高波动板块上的预测稳定性 / 暴露偏差 / 无泄漏可复现  
- **方法**：波动率筛热点；热点期内时序切分；全市场对照；噪声/缺失压力；KS/PSI 监控  
- **指标**：F1 或 MAE；校准；分板块误差；KS/PSI；时延/特征失败率  

### 禁区（出现即改）

买/卖/仓位/荐股/开多开空/目标点位/年化收益当主指标 → **改成**特征定义、切分、KS、分层误差。

**交卷**：ipynb + html + `答题卷.doc` → `参赛号/B2/`

## 卡 F｜B3 默写骨架（Day5）★

口诀：**表·协·标·周·抗·资·链·比**（8 类，缺一不可）

1. **表**：门禁/安防/报修 × 问题 × 核心功能（含技术：人脸/行为检测/NLP 派单）  
2. **协**：门禁/安防事件 → 事件中台 → 等级判断 → 工单派单 → 回写三系统+业主  
3. **标**：3 个可量化（时延/召回/闭环时长等；自拟写「方案建议值」）  
4. **周**：4 阶段总 **10** 周（例 1–2 勘察｜3–4 方案资源｜5–8 试点｜9–10 验收推广）；责任人=角色  
5. **抗**：参与试用｜分层培训+手册｜试点标杆+激励+切换日  
6. **资**：人力/物力/财力 + **到位验证**（名单签到 / 到货验收 / 预算批复）  
7. **链**：业主进小区起 **≥6** 节点：识别→权限→放行/告警→安防复核→中台→工单→处置回写  
8. **比**：操作便捷性 + 信息实时性（两侧都写具体）

### 流程（五模块 + 两判断）

输入 → 预处理 → 高风险检测 → **判断①含高风险?** → 人工审核 → **判断②确认高风险?** → 报告/改判 → 审计归档 → 规则回流  

### JSON 必填（默写）

```json
{
  "rule_id": "R-001",
  "risk_type": "提前解除权",
  "risk_level": "high",
  "keyword_list": ["随时解除合同", "无需承担违约责任"],
  "enable_logging": true,
  "version": "1.0"
}
```

题面硬要求至少出现：`keyword_list`、`enable_logging`。

### 伪代码两句型

- **识别**：校验 → 加载启用规则 → 遍历 clauses → 匹配 keyword_list → 命中记录(+版本/证据) → 按 enable_logging 写日志 → 返回  
- **标记**：鉴权 → 合并人工 decision/reason → 落库 → 更新统计 → 审计日志 → 返回
